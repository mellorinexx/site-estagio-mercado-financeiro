## Projeto

NextStep Finance: ajuda estudantes **universitários** a se prepararem para os processos seletivos de estágio no mercado financeiro. O intuito é mostrar a rotina real de cada área, para cada universitário se conectar com a que combina com ele. Um quiz ajuda nessa decisão, com um formulário final para direcioná-los para vagas reais.

**Tom:** de universitária para universitários, próximo e sem jargão engessado.

**Deploy:** automático na Vercel a cada push na `main`. Nada sobe sem a aprovação da dona do projeto.
